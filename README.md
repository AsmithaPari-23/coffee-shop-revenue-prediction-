# Coffee Shop Revenue Prediction

A machine learning web application that predicts the estimated revenue of a coffee shop based on key business parameters. The project helps users make data-driven decisions by providing accurate revenue predictions through an interactive interface.

## Features

- Predicts coffee shop revenue using machine learning
- User-friendly web interface for input and prediction
- Data preprocessing and feature engineering
- Trained regression model for accurate predictions
- Real-time prediction results

## Tech Stack

**Frontend:** HTML, CSS, JavaScript  
**Backend:** Python, Flask  
**Machine Learning:** Scikit-learn, Pandas, NumPy

## Installation

```bash
git clone https://github.com/AsmithaPari-23/coffee-shop-revenue-prediction.git
cd coffee-shop-revenue-prediction
pip install -r requirements.txt
python app.py
```
